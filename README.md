# 📈 EDA-Stock-Analysis

An exploratory data analysis (EDA) project focused on analyzing stock market data to uncover trends, volatility, and potential correlations.

This repository contains the Jupyter Notebook (`Stock_analysis.ipynb`) where the analysis is performed.

---

## 📋 Overview

This project performs Exploratory Data Analysis on stock price data.

The goal is to visualize key metrics, understand data distribution, and identify patterns that may support further financial analysis or machine learning modeling.

---

## 🔍 Key Objectives

- **Data Cleaning:** Handling missing values and formatting dates.
- **Visualization:** Creating charts to analyze price movements and trading volume.
- **Statistical Analysis:** Calculating returns, volatility, and moving averages.
- **Correlation Analysis:** Identifying relationships between different stocks or financial metrics.
